Beyond the baseline

  • Per-question provenance in the UI — retrieval query, cited pages and hybrid/dense/BM25 scores are shown to the user, not buried in logs.
  • Hybrid retrieval with MMR and session-level chunk exclusion, so no two questions come from the same paragraph.
  • Adaptive difficulty ladder plus a budgeted follow-up mechanism (two per interview).
  • Grading against the source passages, and report statistics that are computed rather than generated.
  • Graceful degradation — runs end to end with no API key via OFFLINE_MODE=1; rate-limited answers are stored ungraded rather than lost.
  • Single-origin Docker build and a Render blueprint; committed vector index so a clone runs without a 90 MB download.

How to verify in five minutes

1 · Installpip install -r backend/requirements.txt
2 · Testscd backend && python -m pytest -q — 22 passing, no API key needed
3 · Index statuspython -m scripts.ingest_kb --status
4 · Runuvicorn app.main:app --port 8000 → UI at /, docs at /docs
5 · Headless demopython -m scripts.demo_interview --role ai_ml_engineer --questions 3
The vector index ships with the repository, so steps 2–5 work on a fresh clone. Rebuilding from source needs scripts.fetch_books then scripts.ingest_kb --all (~40 s with the default local embedder).
